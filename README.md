# ArxCore

Создаю собственное RISC-V ядро для диплома.

Текущее состояние:
- Реализованы расширения RV32IM
- 5 стадийный конвейер (Fetch, Decode, Exec, Mem, Write back) без пересылок (кроме WB -> Decode)
- На физическом уровне Гарвардская Архитектура, на логическом - Архитектура фон Неймана.
- Реализована загрузка программ и дамп ОЗУ через uart.
